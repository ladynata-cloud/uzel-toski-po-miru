# Одна реплика помощника к фрагменту сочинения

Редактор отвечает за черновик, выделение и сохранение правок. Помощник получает одну учебную задачу и возвращает одну текстовую реплику. Ученик сам решает, какой вариант фразы оставить. Этот контракт предназначен для будущей модели. Текущая тренировка работает на устройстве.

## Что передаёт редактор

Версия 1 описывает содержание одного обращения. Все восемь полей обязательны. Пределы строк указаны в единицах длины строки JavaScript (UTF-16).

| Поле | Значение |
|---|---|
| `version` | Число `1` |
| `stage` | `thesis` — тезис, `episode` — деталь сцены, `link` — связь с тезисом, `draft` — фрагмент полного черновика |
| `mode` | `secular` или `orthodox`, согласно выбору ученика |
| `topic` | Вопрос темы, до 500 единиц |
| `workId` | Идентификатор карточки из каталога, до 80 единиц. Для своей книги ученика — пустая строка |
| `workTitle` | Автор и название, до 240 единиц. До выбора книги допустима пустая строка |
| `passage` | Точный текст, выбранный для обсуждения, до 1200 единиц. Для вопроса до начала письма допустима пустая строка |
| `message` | Вопрос или просьба ученика, до 1000 единиц |

При длинном выделении редактор предлагает выбрать конкретное место. Заметки по другим темам, история чата и соседние фразы сохраняются у ученика. Для работы модели с учебными сведениями служат `system.ru.md` и карточка из `catalog.json`, найденная по известному `workId`. Собственное название книги и её пересказ поступают как слова ученика. Если сведений мало, помощник может попросить найти нужное место в книге.

## Что возвращает помощник

Ответ содержит число `version` со значением `1` и строку `reply` с короткой репликой для показа в редакторе. Например, при выделении фразы «Доктор был добрым человеком» уместен вопрос «Где в сцене ты видишь эту доброту и что в тот момент мог почувствовать Мерцалов?». Рекомендуемый объём реплики — несколько предложений. При вопросе об экзамене сначала нужен прямой ответ, при затруднении в письме — один посильный шаг. Вера ученика и соответствие его взгляда позиции мастерской в оценку работы не входят.

Редактор показывает ответ рядом с исходной фразой и оставляет поле для новой версии. Если за время разговора исходная фраза изменилась, актуальное выделение выбирают заново. При смене темы или книги ответ принадлежит той работе, для которой ученик запросил подсказку.

## Как проверять дообученную модель

`turn-cases.json` содержит самостоятельные учебные ситуации. В каждом испытании передают модели только `turn`, затем проверяют её реплику по пунктам `reply_checks`. Это не варианты для подстановки в черновик. В поле `revision_check` указано, что педагог может увидеть в следующей версии ученика. Результат правки фиксируют отдельно и только после её появления. Две ситуации о Куприне используют один фрагмент и разные ракурсы. Их стоит проверять рядом, чтобы убедиться, что светский и православный вопросы одинаково опираются на текст.

## Как помощник выбирает подсказку в опубликованном тренажёре

Экзаменационные правила и подсказки к конкретному выделению обрабатываются на устройстве. Для свободного вопроса есть небольшой обученный классификатор. Он выбирает, с чем просит помочь ученик: тезисом, сценой, объяснением, формулировкой или возможным возражением. При низкой уверенности редактор продолжает обычный пошаговый диалог. Кнопки трудностей доступны при любом результате. Классификатор не выставляет оценку за текст.

Учебный набор содержит 110 синтетических русскоязычных реплик. Для воспроизведения весов запустите из корня репозитория `python3 essay_workshop/assistant/train_intents.py`. Для независимой проверки запустите `node essay_workshop/assistant/check_intents.cjs`. Набор для этой проверки составлен отдельно от учебного. В первой версии из 30 учебных вопросов классификатор верно определил трудность в 23 случаях, ошибся в трёх и воздержался в четырёх. Из шести посторонних реплик он пропустил пять и одной ошибочно назначил учебную подсказку. Эти числа описывают синтетические запросы; качество помощи реальным выпускникам следует оценивать по их самостоятельным правкам.

Для будущего серверного собеседника сборка читает `ESSAY_ASSISTANT_ORIGIN`. По умолчанию это пустая строка. Когда на этом адресе появился сервис, поддерживающий `POST /v1/essay/turn`, в разборе фразы появляется дополнительная отправка. Ученик видит фрагмент и отправляет его со своим вопросом отдельным действием. Готовый HTML для автономной работы не использует этот сервис.

Как получить ключ GigaChat

Ключ для домашнего подключения получает взрослый владелец или администратор проекта в GigaChat API.





    

  1. Войди в Studio через Сбер ID и открой личное пространство.
    2. 

  2. В разделе «Создать проект» выбери «AI-модели», затем «GigaChat API». Введи название проекта и ознакомься с договором.
    3. 

  3. В созданном проекте открой «Настройки API» и нажми «Получить ключ». Скопируй Authorization Key сразу: его показывают один раз.
    4. 

  4. Взрослый вставляет ключ в поле «Ключ авторизации GigaChat» в запущенной на своём компьютере копии тренажёра.
    5.

Подключить API на домашнем компьютере




Распакуй семейный комплект с программой подключения и выполни инструкцию в архиве. Запущенная программа покажет адрес страницы для ввода ключа.


У меня уже есть этот HTML-файл

Для местного подключения нужен Python 3. Сохрани программу рядом с HTML. Открой терминал в этой папке, набери команду ниже и добавь после пробела фактическое имя скачанного HTML в кавычках. В файл с ключом ничего записывать не нужно.

py full_review_server.py --html "имя страницы.html"

В macOS и Linux начни команду с python3. Если при скачивании браузер добавил к имени программы номер, подставь её фактическое имя в кавычках. На Windows можно перетащить файл HTML в окно терминала после --html.

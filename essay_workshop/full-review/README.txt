Начните с practice.html. Нажмите «Начать с одной фразы» или выберите маршрут для своего черновика. Упражнения, полка и сохранение работают без ключа. Для проверки целого текста откройте essay-check.html.

Узел тоски по миру · Проверка итогового сочинения

Распакуйте ZIP. Откройте essay-check.html в браузере, введите тему и напишите
или вставьте свой текст. Самопроверка работает без интернета и ключа.

Для подготовки откройте practice.html. Найдите знакомую книгу на книжной полке,
разберите эпизод и перейдите к собственному тексту. В essay-check.html доступны
проверка, выбор темы, литературные карточки и готовое задание для обычного чата.

Для разбора всего текста в GigaChat понадобится интернет, личный проект
GigaChat API и Python 3.9 или новее. Устанавливать библиотеки через pip не нужно.

Windows: дважды нажмите start-windows.cmd.
macOS или Linux: откройте терминал в папке комплекта и выполните
    python3 full_review_server.py --html essay-check.html --open

Откроется локальная страница. Браузер хранит черновик отдельно для каждого
адреса. Для переноса текста с сайта или из отдельного HTML используйте кнопки
выгрузки и загрузки черновика на странице.

Перед отправкой взрослый владелец личного проекта просматривает тему и весь текст,
вставляет свой ключ авторизации в скрытое поле и нажимает кнопку отправки.
Можно приложить до двух карточек. В предпросмотре видны все выбранные справки.
Методика и примеры вопросов входят в комплект. Переносимая копия содержит версию
на день скачивания. Чтобы получить новые правила и книги, сохраните свой черновик
для переноса и скачайте актуальный ZIP: https://usel-toski-po-miru.art/k-sochineniyu/itogovoe/pomoshchnik/proverka-gigachat.zip

Ключ авторизации берётся в личном проекте GigaChat API. Это другой ключ, чем
sk-ключ посредника для Claude. Тему и текст получает GigaChat. Программа на
компьютере запрашивает временный токен и отправляет работу в одном запросе к модели.
Ключ не записывается в черновик, файл или журнал. Для завершения программы
закройте её окно либо нажмите Ctrl+C.

При ошибке проверки сертификата следуйте официальной инструкции
https://developers.sber.ru/docs/ru/gigachat/certificates
Если сертификат установлен только для приложения, можно указать файл:
    python3 full_review_server.py --ca-file "путь к сертификату PEM" --open
Если порт занят, закройте первый экземпляр или добавьте --port 8767.

Как получить ключ ГигаЧата и проверить сочинение через API

Для обычной проверки в бесплатном чате ключ не нужен. Если вы хотите получить ответ прямо в домашнем редакторе, понадобится личный ключ взрослого, компьютер и интернет.

1. Получите ключ

  1. Войдите в личный кабинет Сбера через Сбер ID. Нажмите «Создать проект». В разделе «AI-модели» выберите «GigaChat API».
  2. Назовите проект, например «Домашнее сочинение», прочитайте соглашение и подтвердите создание проекта. Если проект уже есть, откройте его.
  3. В меню проекта откройте «Настройки API» и нажмите «Получить ключ». Скопируйте строку Authorization Key и сохраните в своём менеджере паролей. Эту строку показывают один раз. Посмотреть, как выглядит окно с ключом.

2. Проверьте весь текст дома

  1. Скачайте комплект для проверки целого сочинения (ZIP) и распакуйте его. Для запуска установите Python версии 3.9 или новее.
  2. В Windows дважды нажмите start-windows.cmd. В macOS или Linux откройте терминал в распакованной папке и выполните python3 full_review_server.py --html essay-check.html --open. Откроется страница на вашем компьютере.
  3. Вставьте тему и сочинение. Раскройте «Получить разбор от GigaChat» и прочитайте текст для передачи. Вставьте ключ только в поле «Ключ авторизации GigaChat» на локальной странице, отметьте согласие и нажмите «Отправить на разбор». Ответ появится в редакторе.

Взрослый владелец аккаунта сам отправляет работу. Личный API доступен полностью дееспособным резидентам РФ от 18 лет. У бесплатного режима есть лимит. Тарифы · Условия личного API.

При ошибке сертификата откройте инструкцию Сбера. Посмотреть шаги в картинках. В скачанном комплекте та же памятка открывается без интернета.

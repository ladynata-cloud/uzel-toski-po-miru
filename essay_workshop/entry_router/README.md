# Подбор первого шага

Кнопка «Подобрать шаг без интернета» читает короткое описание ситуации ученика. Модель предлагает один из семи входов в мастерскую или просит уточнить ситуацию. Переход открывает сам ученик. Идентификаторы маршрутов и их порядок соответствуют `personal-gigachat/navigation-steps.json`. Первый класс в учебных данных называется `none`: ученик начинает без темы и книги. Класс `unknown` означает, что по реплике маршрут определить трудно.

`training.json` содержит 310 придуманных реплик. Код извлекает из них слова, пары слов, языковые признаки и учитывает отрицания внутри части фразы. На этих признаках обучается линейная многоклассовая модель. Пороги для слабого и неоднозначного результата подбираются по четырём частям учебного набора. Логика не требует сетевого вызова. В HTML включаются параметры и код предсказания. Введённый учеником текст не участвует в обучении.

Пересобрать коэффициенты из корня репозитория:

```sh
node essay_workshop/entry_router/train.cjs
```

Проверить воспроизводимость и результаты на отдельно составленных репликах:

```sh
node essay_workshop/entry_router/train.cjs --check --report
```

В независимом наборе `holdout.json` по пять реплик на каждую из восьми меток. Из 35 запросов с учебным маршрутом модель верно определила 19, ошиблась в 5 и воздержалась в 11. Для всех пяти неопределённых либо посторонних запросов модель воздержалась. Эти числа относятся к выбору первого шага на синтетических репликах. Оценки ученических работ и эффект занятия здесь не измерялись.

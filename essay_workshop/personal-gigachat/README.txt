Итоговое сочинение — домашний тренажёр «Узла тоски по миру»

Для занятия без интернета откройте index.html двойным нажатием. Чтение,
редактирование и встроенный помощник работают без регистрации. Ссылки на полные
книги открываются в интернете. Черновики можно скачать со страницы самопроверки.

Чтобы взрослому обратиться к своему ГигаЧату прямо из редактора

1. Распакуйте весь ZIP в отдельную папку. Понадобится Python 3.9 или новее.
   Для Windows запустите start-windows.cmd. Для macOS и Linux в терминале
   из распакованной папки выполните:
       python3 server.py --port 8765 --open

2. Подготовьте ключ авторизации личного проекта GigaChat API, scope
   GIGACHAT_API_PERS. Введите ключ в открывшемся терминале. Символы во время
   ввода скрыты. Ключ хранится в памяти локального процесса. Тариф и остаток
   токенов смотрите в своём аккаунте.
   Личный проект: https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart
   Тарифы: https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs

3. В открывшейся вкладке выберите тему, напишите или вставьте текст. Выделите
   фразу, нажмите «Разобрать фразу», затем «Спросить у моего ГигаЧата».
   Взрослый читает выделение, вводит вопрос и сам нажимает
   «Отправить фрагмент и вопрос». На этой же странице появится ответ.
   ГигаЧат получает этот фрагмент, тему, выбранные книгу и ракурс, вопрос
   и учебные инструкции. Избегайте имён учеников и личных сведений.
   Обсудите подсказку вместе. Вариант правки школьник пишет сам.

4. Чтобы закончить, закройте окно терминала или нажмите Ctrl+C. Для продолжения
   используйте тот же браузер и адрес. Черновик в автономном файле и черновик
   на локальной странице хранятся отдельно. Для переноса скачайте свой текст.

Если ГигаЧат не отвечает

Проверьте подключение к интернету, принадлежность ключа личному проекту,
доступный лимит токенов и требования к сертификатам в официальном быстром
старте. Если для вашего устройства Сбер требует дополнительный корневой
сертификат, следуйте официальной инструкции. Мост принимает путь к доверенному
файлу CA в формате PEM через переменную GIGACHAT_CA_FILE. Проверка TLS включена.
Если порт 8765 занят, его можно заменить: python3 server.py --port 8766 --open.
Записи для другого порта хранятся в браузере отдельно.

Кто пользуется API

Этот режим предназначен для личных запросов взрослого владельца индивидуального
аккаунта. По условиям API это полностью дееспособный резидент РФ от 18 лет.
Взрослый может сам обратиться за подсказкой и обсудить её с ребёнком. Ключ,
аккаунт и доступ к нему остаются у владельца. Для своего класса не размещайте
эту программу на общем сервере и не рассылайте настроенный ключ ученикам.
Индивидуальный Freemium предусматривает личное некоммерческое использование
с лимитами. Перед первым запросом проверьте условия своего подключения.
https://developers.sber.ru/docs/ru/policies/gigachat-agreement/individuals

Для обычного ГигаЧата есть отдельная ссылка в разборе фразы. Вы можете
скопировать задание и сами вставить его в официальный чат. Для лиц до 18 лет
условия веб-сервиса требуют согласия и контроля родителя или другого законного
представителя, который сам принял эти условия.
https://developers.sber.ru/docs/ru/policies/gigachat/agreement

Выбор следующего упражнения с ГигаЧатом

На старте раскройте «Помочь выбрать шаг с ГигаЧатом» и кратко опишите
затруднение. В задание попадут это описание, выбранный в мастерской ракурс
и список упражнений. Скопируйте задание и откройте ГигаЧат в отдельной
вкладке. Вернувшись с ответом, выберите предложенный номер и нажмите
«Перейти к этому шагу». Для перехода и самих упражнений интернет не нужен.
Если взрослый уже запустил server.py, он также может нажать «Спросить
через мой личный ГигаЧат». Программа получит номер и покажет его здесь.

Для печати откройте файл pamyatka-2026-27.pdf из этой же папки. Он доступен без интернета.

## Необходимая интеграционная работа

Новый тест отказа хранилища из PR 44 должен раскрыть дополнительный маршрут,
который PR 43 помещает в закрытый details. Исправление использует настоящий
фокус и Enter, проверяет открытие и сохраняет все прежние проверки записи,
отметок и скачанного текста.

Для иллюстрированной статьи добавляется воспроизводимая съёмка шести
состояний собранного интерфейса. Используются только явно учебные
тексты, локальные страницы и автономный комплект. Внешние API не вызываются.
Снимки сохраняются в CI artifact, а не в исходниках сайта.

Workflow дополнительно выполняет существующие семь офлайн-тестов
бюджетного runner из PR 42 и создание изображений после браузерных gates.
Условия существующих проверок не меняются.

## Gates перед выпуском

1. Сборка и проверка ссылок для собственного домена и GitHub Pages.
2. Все существующие Python release tests и personal-gigachat tests;
   дополнительно `test_bonus_training.py`.
3. Семь существующих Node unit suites, включая quote-evidence,
   синтаксис и воспроизводимость входного навигатора.
4. Все восемь браузерных suites из общего reader-checks workflow;
   нативное выделение второго одинакового фрагмента клавиатурой сохраняется.
5. Независимое статическое ревью общей композиции и интеграционных изменений.
6. Проверка актуального remote main непосредственно перед merge.
7. После публикации — успешный Pages deployment, сравнение значимых
   опубликованных файлов с проверенной сборкой и проверка скачиваемых пакетов.

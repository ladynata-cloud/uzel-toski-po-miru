- Task: исправление подмены произведения по одному совпадению автора.

- Date: 2026-11-19.

## Goal

Читатель получает подходящее произведение либо просьбу уточнить запрос.
Знакомая фамилия автора не должна превращать неизвестное название в ответ
о другой книге. Материалы двух существующих статей доступны помощнику
с сохранением границы между первым чтением и обсуждением прочитанного.

- На проверенном `main` запрос «Тоска Чехова» приводит к «Студенту»,
  а «Куст сирени Куприна» — к «Чудесному доктору».
- Оба разбора уже опубликованы из `article_data/`, но отсутствуют среди
  19 карточек первого чтения.
- Локальный помощник использует `dist/assets/reader-search.js`;
  `reader_search.py` создаёт страницу, `reader_catalogue.py` — JSON v1.
- Экспорт обсуждения сейчас связывает карточки с каталогом и занятиями.
  Для двух новых карточек требуется поддержать существующие статьи.
- Общая серверная подготовка ведётся отдельно в
  [MathExam](https://github.com/ladynata-cloud/math-exam-fipi).

## Approved scope

### In scope

- Отдельная проверка авторского и содержательного совпадения, уточнений
  и явно процитированных фрагментов запроса.
- Две короткие карточки по существующим статьям без разглашения развязки.
- Связь этих карточек с существующими разборами и их источниками в экспорте v1.
- Регрессионные сценарии и проверки для подготовки помощника.
- Сборка сайта для собственного домена и GitHub Pages; локальный commit.

### Out of scope

- Новые литературные статьи, массовая редактура корпуса, новые цитаты и изображения.
- Настройка сервера, запросы к моделям, обучение, публикация и deployment.
- Merge, force, reset, rebase и правки других репозиториев.

## Acceptance criteria

- [x] Два исходных запроса находят именно запрошенные произведения.
- [x] Неизвестное название с известным автором не подменяется другой книгой
      в проверенных сценариях; произвольное понимание литературного запроса не заявляется.
- [x] Запрос по одному автору допускает несколько вариантов, уточнение сужает их.
- [x] Первые ответы и экспорт первого чтения не раскрывают развязки новых рассказов.
- [x] В обсуждении доступны исходные комментарии мастерской, задания и ссылки;
      прежние отметки проверки источников не повышаются без новой сверки.
- [x] Контракт экспорта v1 сохраняется; проверки проходят для обоих адресов.

## Checks and gates

- Required tests: `node --test tests/reader-search.test.cjs` после сборки;
  проверки новых экспортированных записей и пользовательских запросов.
- Required static checks: `python3 build.py`, `python3 verify_site.py`,
  синтаксис существующих JS, `git diff --check`.
- Manual checks: тексты карточек сверены с имеющимися статьями; первые ответы
  отделены от обсуждения; итоговый diff ограничен задачей.
- Final gate marker: `READER_WORK_MATCHING_PRETRAINING_PASS` после проверок.
- Not run: обучение и запросы к моделям, production после выпуска.

## Review plan

- Проверка кода, целевые регрессии и содержательная вычитка двух карточек.
- Новый учебный тренажёр не создаётся; консультация по учебной последовательности
  не применяется. Независимый обзор подготовленного diff запрашивается у root.
- Внешний провайдер review не привлекается; внешнее одобрение не заявляется.

## Risk and rollback

- Более осторожный поиск может просить уточнение вместо догадки по фамилии.
  Сохраняются проверенные запросы по деталям, полным названиям и одному автору.
- Добавлен вид `article` в существующий экспорт; поля v1 сохраняются,
  совместимость общего снимка отдельно проверяется в MathExam.
- Откат — revert коммита после решения владельца. Пользовательские данные
  не меняются; локальный режим остаётся доступен.

## Permissions

- Работа разрешена текущим прямым указанием владельца «выполни всю возможную
  работу до передачи помощников в обучение» и ограничена поручением root.
- Branch и локальный commit разрешены.
- Push и Draft PR выполняет root после проверки результата.
- Merge, auto-merge и deployment не разрешены.

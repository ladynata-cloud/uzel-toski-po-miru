## Проверка и границы

Сборка и verify_site.py для основного домена и GitHub-подкаталога; существующие тесты поиска/читательской мастерской; шесть регрессионных тестов черновика. Новые тесты включены в оба существующих workflow.

Визуальная и интерактивная проверка охватывает главную, поиск/пошаговое чтение, раздел об авторах и обычный/экзаменационный редактор черновика, в том числе мобильную ширину. Проверка внутренних ссылок охватывает сгенерированный сайт; это не новая литературоведческая экспертиза всех 553 страниц и не проверка доступности каждого внешнего источника. Содержание произведений и цитаты не переписываются; платные API не используются.
